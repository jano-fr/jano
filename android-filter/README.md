# JANÔ 0.7.0 bêta 1

Application Android de filtrage local et de suivi manuel des comptes. Même identifiant et même clé de signature que les versions précédentes : installer par-dessus, sans désinstaller.

L'onglet Listes montre les comptes de la liste verte classés par réseau. « Ouvrir le profil » ouvre l'application officielle. L'utilisateur s'abonne lui-même, puis choisit « Abonné.e ! » dans le bandeau pour enregistrer son choix et retourner dans JANÔ. Les comptes confirmés passent en bas de leur réseau. L'état est stocké localement et correspond à une confirmation de l'utilisateur, sans vérification automatique auprès du réseau. Si le service d'accessibilité est indisponible, une confirmation est proposée au retour dans JANÔ.

Le filtre utilise le service d'accessibilité activé par l'utilisateur. Le service attend les événements du système et l'analyse du fil ne démarre que sur un réseau sélectionné. Les deux listes signées sont actualisées avant leur expiration si une connexion est disponible.

Consulter VALIDATION.md pour les points à vérifier sur téléphone et les limites liées à Android et aux applications sociales.
