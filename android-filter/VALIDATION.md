# Validation JANÔ 0.7.0 bêta 1

Sur un téléphone, vérifier que l'accessibilité est activée et connectée. Dans Listes, choisir un réseau, ouvrir un profil, suivre manuellement le compte, puis appuyer sur « Abonné.e ! » dans le bandeau : JANÔ doit revenir sur ce réseau, marquer le compte et le déplacer en bas. Vérifier que fermer le bandeau ne marque pas le compte, que le statut persiste après fermeture et que changer de réseau ne mélange pas les comptes.

Si le service n'est pas connecté ou si Android ne peut pas afficher le bandeau, revenir dans JANÔ et confirmer dans la fenêtre proposée. Aucune action automatique de suivi n'est exécutée. Une application de nettoyage ou d'économie d'énergie peut interrompre le service d'accessibilité. Le retour direct par le bandeau dépend des règles de démarrage Android et doit être vérifié sur l'appareil.
